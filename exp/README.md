# Experiment archive

Calibration runs behind the lesson numbers. The page build does not read this folder.

| Directory | What it holds |
|---|---|
| `config/` | Batch inputs |
| `tools/` | Node and Python scripts that produced the runs |
| `logs/` | Probe text |
| `out/` | Raw results |
| `plots/` | Figures cited by the log |

The log is [`docs/EXPERIMENTS.md`](../docs/EXPERIMENTS.md). Run tools from the repository root, for example `node exp/tools/sum.js exp/out/b10.jsonl`.
